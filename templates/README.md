# Templates

此資料夾僅存放樣板，用於產生規格、任務、指令與 VS Code 設定等內容，**不要直接覆蓋實際實作檔案**。

## 內容

- `spec-template.md`, `plan-template.md`, `tasks-template.md` — 規格/計畫/任務樣板。
- `agent-file-template.md`, `checklist-template.md` — Agent 文件與檢查表樣板。
- `commands/`, `prompts/` — 各代理指令/提示樣板。
- `vscode-settings.json` — VS Code 建議設定樣板。

## 使用指引

1. 以樣板複製或套用到新檔案，再根據實際需求編寫。
2. 更新樣板時，請同步檢查相關文件是否有引用，避免過時內容。
