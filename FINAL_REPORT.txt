  --set-secrets HUGGINGFACE_TOKEN=huggingface-token:latest \
  --image gcr.io/your-project/transcription:latest

================================================================================
常見問題快速答案
================================================================================

Q: Token 應該存儲在哪裡?
A: 本地開發: .env 文件 (加入 .gitignore)
   Cloud Run: Cloud Run Secrets (推薦)
   Kubernetes: Kubernetes Secrets
   Docker: 運行時環境變數

Q: 如何驗證 Token 是否有效?
A: 運行驗證腳本:
   python quick_hf_check.py          (30 秒快速檢查)
   python verify_huggingface_token.py (完整驗證)

Q: Token 過期了怎麼辦?
A: 在 https://huggingface.co/settings/tokens 生成新 token
   然後更新部署配置

Q: 模型條款是什麼?
A: Pyannote 要求接受使用條款
   訪問 https://huggingface.co/pyannote/speaker-diarization
   並點擊 Accept 按鈕

Q: 支持哪些環境?
A: 本地開發 + Docker + Cloud Run + Kubernetes
   所有環境都支持，配置方式各異

Q: 如果 Pyannote 加載失敗怎麼辦?
A: 系統會自動回退到 EmbeddingClusterDiarizer
   但建議先解決 Pyannote 配置問題

Q: 如何監控 Token 的使用?
A: 檢查 Cloud Run 日誌中的 diarization 相關日誌
   監控 API 調用失敗率
   定期檢查 Token 過期時間
