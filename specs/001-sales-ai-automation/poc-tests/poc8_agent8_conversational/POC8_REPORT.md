### 月成本估算

**假設**：
- 每天 10 次查詢
- 每月 30 天
- 總計：300 次查詢/月

**Gemini 2.0 Flash 定價**（2025-11-04）：
- Input：$0.075 / 1M tokens
- Output：$0.30 / 1M tokens

**計算**：
```
Input:  300 × 1000 tokens × $0.075 / 1M = $0.0225
Output: 300 × 1000 tokens × $0.30 / 1M  = $0.09
總計: $0.11/月
```

**實際成本**：**約 $0.11/月** ✅（極低）

## 🎯 優勢與亮點

### 1. 智能上下文理解 🧠

- **實體提取**：從歷史中提取業務名字、案件 ID
- **對話連貫**：多輪對話邏輯清晰

### 2. 話題切換處理 🔄
- **自動檢測**：準確檢測問題類型和參數變化
- **重新查詢**：自動重新搜集資訊

### 3. 高質量回答 ⭐
- **結構化輸出**：簡短總結 + 數據 + 洞察 + 建議
- **量化指標**：具體數字，避免模糊描述
- **可執行建議**：明確「誰做什麼，何時完成」

### 4. 繁體中文支持 🇹🇼
- **台灣用語**：「案件」、「業務」、「主管」
- **友善語氣**：專業但親切，正面鼓勵

### 5. 極低成本 💰
- **$0.11/月**：遠低於預期
- **按需付費**：只在使用時付費
- **無基礎設施成本**：復用現有 Cloud Run

## ⚠️ 限制與待改進

### 1. API 配額限制
**問題**：Gemini 2.0 Flash Exp 每分鐘 10 次請求
**影響**：密集測試時會觸發限制
**解決方案**：
- 生產環境使用 Gemini 2.0 Flash（配額更高）
- 實現請求節流（rate limiting）
- 添加重試機制

### 2. 回答洞察力可以更深入
**問題**：洞察部分有時略顯表面
**改進方向**：
- 優化 Prompt（已完成 v2）
- 提供更多範例
- 調整 temperature 參數

### 3. 缺少數據視覺化
**問題**：純文字回答，缺少圖表
**改進方向**：
- 添加簡單的文字圖表（ASCII art）
- 生成 Markdown 表格
- 未來整合圖表生成工具

### 4. 對話歷史儲存
**問題**：目前只在記憶體中，重啟後消失
**改進方向**：
- 儲存到 Firestore
- 設置過期時間（如 7 天）
