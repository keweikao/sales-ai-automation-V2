## 💡 關鍵亮點

### 1. 智能對話能力 🧠

- **上下文理解**：記得前面討論的內容
- **代詞指代**：「他」、「這個」等自動推斷
- **話題切換**：檢測並重新查詢數據

### 2. 高質量回答 ⭐

- **結構化**：簡短總結 + 數據 + 洞察 + 建議
- **量化**：具體數字，避免模糊
- **可執行**：建議明確「誰做什麼，何時」

### 3. 繁體中文支持 🇹🇼

- **台灣用語**：「案件」、「業務」、「主管」
- **友善語氣**：專業但親切
- **文化適配**：符合台灣業務場景

### 4. 極低成本 💰

- **$0.11/月**：每天 10 次查詢
- **按需付費**：只在使用時付費
- **無基礎設施成本**：復用現有 Cloud Run
