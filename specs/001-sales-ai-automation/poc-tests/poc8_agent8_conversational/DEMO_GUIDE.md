# Agent 8 演示指南

**演示時間**：15 分鐘
**準備時間**：5 分鐘
**適合對象**：業務主管、技術團隊、產品經理

---

## 🎯 演示目標

展示 Agent 8 的核心能力：

1. **自然語言理解**：用繁體中文提問，自動理解問題意圖
2. **數據查詢分析**：精準查詢相關案件數據
3. **洞察和建議**：提供有價值的業務洞察
4. **多輪對話**：理解上下文和代詞指代
5. **話題切換**：自動檢測並重新搜集資訊

---

## 📋 演示腳本

### 開場白（1 分鐘）

```
大家好！今天要展示的是 Agent 8 - 業務主管的智能助理。

Agent 8 讓主管可以用自然語言隨時詢問團隊數據，
獲得即時的洞察和建議，不必等待固定的報告。

現在讓我展示 5 個核心能力...
```

### 場景 1：團隊整體分析（3 分鐘）

**問題**：「今天團隊表現如何？」

**展示重點**：

- ✅ 自動識別為「團隊整體」問題類型
- ✅ 查詢所有 30 個案件
- ✅ 提供結構化回答：
  - 📊 關鍵數據（案件數、平均健康度）
  - 💡 洞察（發現健康度分布差異大）
  - ✅ 建議（經驗分享、個案輔導）

**說明點**：

```
看，Agent 8 用繁體中文回答，語氣專業友善。
回答結構很清晰：數據 + 洞察 + 建議。
注意這些建議都很具體，例如「安排林雅婷分享成功經驗」。
```

### 場景 2：個人績效深入（3 分鐘）

**問題**：「王小明的情況詳細說明？」

**展示重點**：

- ✅ 話題從「團隊」切換到「個人」
- ✅ 檢測到話題切換，重新查詢數據
- ✅ 只查詢王小明的 7 個案件
- ✅ 提供個人化分析

**說明點**：

```
主管切換話題，從團隊聚焦到王小明。
Agent 8 檢測到這是話題切換（元數據顯示「話題切換: 是」）。
它自動重新查詢，只返回王小明的案件。
```

### 場景 3：代詞指代理解（3 分鐘）

**問題**：「他最好的案件是哪個？」

**展示重點**：

- ✅ 「他」= 王小明（從對話歷史推斷）
- ✅ 元數據顯示「包含代詞: 是」
- ✅ 回答中明確提及「王小明」
- ✅ 回答「海鮮大排檔」（健康度 95 分）

**說明點**：

```
主管用代詞「他」追問，沒有明確說是誰。
Agent 8 從對話歷史中推斷「他」指的是「王小明」。
這就是多輪對話的能力 - 它記得前面在討論什麼。
```

### 場景 4：風險案件分析（3 分鐘）

**問題**：「健康度低於 50 的案件有哪些？」

**展示重點**：

- ✅ 再次話題切換（從個人績效 → 風險案件）
- ✅ 精準篩選：只返回健康度 < 50 的案件
- ✅ 識別風險並給出建議

**說明點**：

```
主管關注重點改變了，想看風險案件。
Agent 8 檢測到話題切換，重新查詢數據。
它不僅列出風險案件，還分析了原因並給出具體建議。
```

### 場景 5：競品情報（2 分鐘）

**問題**：「Eats365 最近被提到幾次？」

**展示重點**：

- ✅ 問題類型切換到「競品情報」
- ✅ 查詢包含 Eats365 的案件
- ✅ 提供競品分析和應對策略

**說明點**：

```
主管又切換話題，想了解競品情況。
Agent 8 查詢提到 Eats365 的案件，
分析客戶對競品的評價，並給出應對策略。
```

## 💡 展示技巧

### 強調重點

1. **繁體中文**：
   - 「看，回答都是繁體中文，用台灣的業務用語」
   - 指出「案件」、「業務」、「主管」等詞彙

2. **多輪對話**：
   - 「注意元數據顯示『話題切換: 是/否』」
   - 「它記得前面在討論什麼人或什麼事」

3. **洞察品質**：
   - 「不只是列數據，還分析為什麼」
   - 「建議很具體：誰、做什麼、什麼時候」

4. **極低成本**：
   - 「每月成本只要 $0.11，幾乎可以忽略」
   - 「按需付費，只在使用時才有成本」

### 處理問題

**Q: 如果問錯問題怎麼辦？**

```
A: Agent 8 會盡力理解，如果真的無法理解，
   會友善地建議其他問法。
   這是 AI 的優勢 - 容錯能力強。
```

**Q: 數據從哪裡來？**

```
A: 來自 Agent 1-6 已經分析好的結構化數據。
   Agent 8 不重複分析，只是彙總和洞察。
   這樣既快又準確。
```

**Q: 可以問什麼問題？**

```
A: 支持 6 大類問題：
   • 團隊整體表現
   • 個人業務績效
   • 案件詳細分析
   • 競品情報
   • 產品需求洞察
   • 趨勢對比
```
