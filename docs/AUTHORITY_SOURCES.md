# Authority Sources

單一入口，列出專案的權威文件與優先閱讀順序，避免重複或版本落差。

## 優先順序

1. `QUICK_START_FOR_AI.md` — AI 助理起手式與工作流程（唯一官方 Quick Start）。
2. `DEVELOPMENT_LOG.md` — 決策與進度的時間序紀錄。
3. `memory/constitution.md` — 成本、效能、品質等核心原則。
4. `specs/001-sales-ai-automation/spec.md` — 需求與使用者故事。
5. `specs/001-sales-ai-automation/plan.md` — 技術架構與成本規劃。
6. `specs/001-sales-ai-automation/research.md` 與 `specs/001-sales-ai-automation/poc-tests/` — POC 驗證與測試腳本。
7. `DEVELOPMENT_GUIDELINES.md`、`PRE_DEVELOPMENT_CHECKLIST.md` — 補充規範（以 Quick Start 為主要入口）。

## 補充參考

- `docs/`：安裝、本地開發、MCP 最佳實踐、部署指南等。
- `templates/`：規格/任務/指令樣板（僅供產生內容，勿直接覆蓋實作）。
- `AGENTS.md`：新增/維護 Specify CLI agent 支援時的必讀規範。
- `memory/codex_cli_memory.md`：Codex CLI 使用的注意事項與上下文提示。
