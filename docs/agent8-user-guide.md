## 什麼是 Agent 8？

Agent 8 是您的專屬智能助理，幫助您隨時了解團隊業務狀況、個人績效和案件分析。

**主要功能**：

- ✅ 用繁體中文自然提問
- ✅ 即時查詢團隊數據
- ✅ 獲得業務洞察和建議
- ✅ 支持多輪對話
- ✅ 自動追蹤話題

## 快速開始

### 1. 在 Slack 中使用命令

在任何 Slack 頻道或私訊中輸入：

```
/ask-agent8 今天團隊表現如何？
```

### 2. 等待回答

Agent 8 會：

1. 🤔 分析您的問題
2. 📊 查詢相關數據
3. 💡 生成洞察和建議
4. 💬 用繁體中文回答您

### 3. 繼續提問

可以追問或切換話題：

```
/ask-agent8 王小明的情況詳細說明？
/ask-agent8 他最好的案件是哪個？
```

## 高級功能

### 多輪對話

Agent 8 會記住您剛才在討論什麼：

```
用戶: /ask-agent8 今天團隊表現如何？
Agent 8: [回答團隊整體情況...]

用戶: /ask-agent8 王小明的情況詳細說明？
Agent 8: [切換到王小明，重新查詢數據...]

用戶: /ask-agent8 他最好的案件是哪個？
Agent 8: [理解「他」= 王小明，回答最佳案件...]
```

### 代詞指代

Agent 8 理解常見代詞：

- **他/她** → 前面提到的人
- **這個/那個** → 前面提到的案件/功能
- **這些/那些** → 前面提到的一組案件

### 話題切換

當您切換話題時，Agent 8 會：

1. 🔄 檢測到話題改變
2. 🔍 重新查詢新話題的數據
3. 💬 聚焦新話題回答

## 使用技巧

### ✅ 好的提問方式

1. **具體明確**

   ```
   ✅ 王小明本週健康度低於 60 的案件有哪些？
   ❌ 王小明的案件
   ```

2. **指定時間範圍**

   ```
   ✅ 本週團隊平均健康度是多少？
   ❌ 團隊平均健康度是多少？
   ```

3. **一次問一個問題**

   ```
   ✅ 今天團隊表現如何？
   ❌ 今天團隊表現如何？王小明怎麼樣？陳美玲呢？
   ```

### ⚠️ 注意事項

1. **權限限制**：Agent 8 僅開放給業務主管使用
2. **數據範圍**：查詢的是 Agent 1-6 分析完成的案件
3. **回答速度**：通常 5-8 秒內回覆
4. **隱私保護**：回答僅您可見（使用 Ephemeral 訊息）

## 常見問題

### Q1: 為什麼收到「沒有權限」訊息？

**原因**：Agent 8 目前僅開放給業務主管使用。

**解決方法**：

- 聯絡系統管理員申請權限
- 確認您的 Slack 帳號已設定主管角色

### Q2: Agent 8 沒有回應怎麼辦？

**檢查步驟**：

1. 確認命令格式正確：`/ask-agent8 您的問題`
2. 等待 10-15 秒（第一次查詢可能較慢）
3. 檢查 Slack 是否有錯誤訊息
4. 如果問題持續，聯絡技術支援

### Q3: 可以查詢多久以前的數據？

**預設範圍**：

- 如果沒指定時間，預設查詢「最近 7 天」
- 可指定：今天、本週、上週、本月、上月

**範例**：

```
/ask-agent8 上月團隊平均健康度是多少？
```

### Q4: Agent 8 的回答準確嗎？

**數據來源**：

- 來自 Agent 1-6 已分析的結構化數據
- 數據準確性與 Agent 1-6 分析品質一致

**AI 生成**：

- 洞察和建議由 Gemini AI 生成
- 建議供參考，實際決策請結合您的專業判斷

### Q5: 如何清除對話歷史？

對話歷史會自動保留，讓多輪對話更流暢。如需重新開始新話題，直接提問新問題即可，Agent 8 會自動檢測話題切換。
